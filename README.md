# 🧠 Logic Quiz

Um quiz de raciocínio lógico com pontuação e classificação final,
construído do zero com HTML, CSS e JavaScript puro.

---

## 💡 Por que esse projeto existe

Aprendi que lógica não é só uma habilidade técnica, é uma forma
de pensar. Passei anos diagnosticando falhas em sistemas e hardware,
e o raciocínio que eu usava lá é o mesmo que estou usando para escrever código.

Esse projeto nasceu de uma ideia simples: Queria praticar lógica de
programação construindo algo que também testa lógica de raciocínio.
Duas práticas em uma.

---

## 🚀 Funcionalidades

- Perguntas de múltipla escolha  
- Sistema de pontuação por acertos
- Armazenamento de dados no navegador (localStorage)  
- Interface simples e intuitiva
- Classificação final baseada no desempenho
- Timer por pergunta
