# 🧠 Logic Quiz

Jogo de lógica interativo com perguntas de múltipla escolha, sistema de pontuação e ranking de jogadores.

---

## 🚀 Funcionalidades

- Perguntas de múltipla escolha  
- Sistema de pontuação  
- Ranking com os melhores jogadores 
- Armazenamento de dados no navegador (localStorage)  
- Interface simples e intuitiva  

---

## 🛠️ Tecnologias utilizadas

- HTML  
- CSS  
- JavaScript  

---

## 🎯 Objetivo do projeto

Projeto desenvolvido com foco em consolidar lógica de programação e criar uma experiência interativa simples para o usuário, simulando um sistema de quiz com ranking.
